# SDLC - Software Development Life Cycle

1.  Planning
2.  Analysis
3.  System Design:

        Database Design:
          - Determining Entities
          - Determining Attributes For Each Entities
          - Relationship Among Entities
          - Resolving Many to Many Relationship

        Relationship Cardinality:
          1. One-to-One (1:1)
          2. One-to-Many (1:N)
          3. Many-to-One (N:1)
          4. Many-to-Many (N:N)

        Entity-Relationship (ER) diagram:
          ER diagram is a diagram that shows entities, their attributes and the relationships between them

4.  Building
5.  Testing
6.  Deployment
